# Frothy

> Frothy is a small language that runs on ESP32 and RP2040 boards. You send code to the board over USB serial while it runs, and you can define a word again while a program uses it. Frothy is not Forth.

Frothy has its own syntax. Forth, Arduino C or MicroPython code does not load. Read the agent guide first. This index matches Frothy {{ site.Params.frothyRelease }}.

The rules in short:

- Define a word with `to name with a, b [ ... ]`. Call it with `name: a, b`. Call a word with no arguments with `name:`.
- Compare integers with `=` and `<>`, not `==` or `!=`. Start a comment with `--`.
- Numbers are integers. There are no floats and no bit operators.
- Inside `[ ... ]`, a line break or a `;` ends an expression.
